# Financial-Research-Agent
My project proposes an Agentic AI-based Financial Research and Analytics system that generates evidence-supported insights for a selected company over a specified time period [Does not predict, rather runs research on past data].Financial research requires collecting and analyzing information from multiple sources such as financial data, stock-market data, and relevant news and manually gathering, processing, and interpreting this information can be time-consuming and repetitive.
Traditional analysis may require users to switch between multiple tools and sources before arriving at meaningful insights, which can be tedious at times🙂‍↕️
So We can use Agentic AIs and they can automate and coordinate these tasks through specialized AI agents.
The proposed system combines Agentic AI, Large Language Models, and Data Science techniques to generate evidence-supported financial research insights.
